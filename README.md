# AE2 × MI: Output Lock Card

A **NeoForge 1.21.1** addon that connects **Applied Energistics 2** and **Modern Industrialization**.

It adds an upgrade card, the **Output Lock Card**, for AE2's Pattern Provider. When the card is installed and the
provider faces an MI machine, every pushed pattern locks the machine's output slots so that the machine can produce
**only the products listed in the pattern**.
